## What was vendored, and what was not

571 of 601 exercises (`category ∈ {cardio, olympic}` dropped), Spanish prose only, with
`name_en` kept as a search index and the unused columns removed — roughly 30% of the
source bytes, and one language of three. **No images are committed to this repository.**
They are mirrored once into this deployment's own R2 bucket by
`scripts/exercises-populate.mjs`, byte-for-byte, and served only to signed-in athletes
through `GET /api/exercises/img/…`.

## Refreshing

RepDB moves a few times a year at most. The runbook is in `docs/setup.md`:

```
pnpm exercises:prune      # re-vendor catalog.json + src/lib/exercise-meta.ts
pnpm test                 # label completeness and catalogue integrity
pnpm exercises:populate   # mirror the new generation's images into R2
git commit && pnpm deploy # populate BEFORE deploy, or images 404 until it lands
```

If `schema_version` has moved past 3 the prune script stops rather than guessing, and the
projection has to be reviewed against the new schema first.
