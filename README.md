# La Mitja 2027

Training tracker for a sub-1:20 half marathon at **La Mitja de Granollers, 24 January
2027**. One athlete, one 23-week block, one Cloudflare Worker.

Activities sync from Strava; the plan is written by hand in the app; everything else —
whether a session was completed, weekly volume against target, progress toward the goal —
is derived on read.

## Running it

```bash
pnpm install
cp .dev.vars.example .dev.vars   # then fill in the four secrets
pnpm db:migrate:local
pnpm dev
```

| Command | Does |
|---|---|
| `pnpm dev` | Astro dev server (workerd via the Cloudflare vite plugin) |
| `pnpm build` | `dist/client` (assets) + `dist/server` (worker) |
| `pnpm preview` | wrangler dev against the built output, on the local D1 |
| `pnpm test` | vitest — pure logic only, no bindings needed |
| `pnpm typecheck` | `astro check` |
| `pnpm db:generate` | regenerate migrations from `src/lib/db/schema.ts` |
| `pnpm db:migrate:local` / `pnpm db:migrate` | apply migrations locally / remotely |
| `pnpm cf-typegen` | regenerate `worker-configuration.d.ts` after editing `wrangler.jsonc` |
| `pnpm deploy` | build and deploy |

Fire the nightly cron without waiting for the clock, against `pnpm preview`:

```bash
curl "http://localhost:8787/cdn-cgi/handler/scheduled?cron=0+3+*+*+*&format=json"
```

## Layout

```
src/lib/          block, activity, plan, metrics, seed — pure, unit-tested
                  strava, sync, state, auth, crypto    — the side effects
src/pages/api/    data (one read), plan/* (writes), sync, login, strava/*
src/components/   Dashboard (home), Planner (/plan), and the pieces they share
docs/             race analysis, injury history, the 22-week plan
migrations/       generated by drizzle-kit — never hand-edited
```
